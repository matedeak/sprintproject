# Mor Anna Bakery — Sprint Project

A mobile-first multi-page bakery website created as part of my Multimedia Design studies at Business Academy Aarhus.

## About the project

The goal of this sprint project was to create a clear and visually engaging digital experience for a bakery, from discovering products to placing a pre-order.

I worked on the visual design, content structure, navigation and frontend implementation of the website.

## What I focused on

- UI and visual design
- Content hierarchy and digital communication
- Customer journey from browsing to ordering
- Multi-page website navigation
- HTML and CSS implementation
- Mobile-first web design
- Consistent branding across pages

## Pages

- Home
- Menu
- Pre-order
- Cart
- Checkout

## Technologies

- HTML5
- CSS3
- GitHub
- GitHub Pages

## What I learned

This project helped me develop my frontend skills while connecting them with my previous experience in digital marketing and communication.

I particularly focused on translating a visual concept into a functional website, maintaining consistency across several pages, and creating a straightforward customer journey.

This is an educational student project created during my Multimedia Design studies and is not an official website for Mor Anna.
